Lab 8 · Bayes’ Rule, Markov Chains & Hidden Markov Models

Measurement models, state transition models and recursive Bayesian state estimation

From Bayes’ rule to hidden Markov models: measurement updates, Markov chains, and the forward algorithm.
NoteAbout this edition

English text and comments were edited for publication. Outputs are archived notebook results, not newly executed results. Lab scaffolds and reference illustrations were supplied by the course. Source and reproducibility notes.

TipSummary

This lab builds up the probabilistic machinery of state estimation step by step. Bayes’ rule is applied to two textbook examples, then to a measurement model (a noisy door sensor). A state transition model is introduced with a coin-tossing Markov chain and a weather Markov chain, where belief propagation becomes a matrix–vector product. Combining the two yields the hidden Markov model: the belief over the door state after repeated observations, the evaluation and decoding problems for the weather/mood HMM, and a generic forward algorithm. An appendix contains short PCA experiments done during the same session.

3. State Transition Model (without Control)

3.1 Example 1: Coin tossing

  • State set \(X = \{HH, HT, TH, TT\}\)

  • State transition probability matrix \(P_{x'x}\)

    • \(p(x_{t+1}=HH | x_{t}=HH) = 1/4\)
    • \(p(x_{t+1}=HT | x_{t}=HH) = 1/4\)
    • \(p(x_{t+1}=TH | x_{t}=HH) = 1/4\)
    • \(p(x_{t+1}=TT | x_{t}=HH) = 1/4\)
    • \(\dots\)

The belief is the probability distribution over the state:

\(bel(x_t) = p(x_t)\), with \(bel \in \mathbb{R}^{|X|}\)

import numpy as np
################## Fill Your Code! ##################
# Belief Initialization (Uniform)
bel = 1/4*np.ones((4,1))
#####################################################
print(bel)
[[0.25]
 [0.25]
 [0.25]
 [0.25]]

The state transition matrix \(P_{x'x}\) has as entries the probabilities \(p(x_{t+1} | x_t)\) of moving from state \(x_t\) to state \(x_{t+1}\):

\(P_{ij} = p(x_{t+1}= i| x_t=j)\)

In this example every transition probability equals 1/4.

################## Fill Your Code! ##################
# Define State Transition Matrix
P = 1/4 * np.ones((4,4))
#####################################################
print(P)
[[0.25 0.25 0.25 0.25]
 [0.25 0.25 0.25 0.25]
 [0.25 0.25 0.25 0.25]
 [0.25 0.25 0.25 0.25]]

How do we compute the state probabilities after one transition?

The relation between \(bel(x_{t})\) and \(bel(x_{t+1})\) through the state transition probabilities is

\(bel(x_{t+1}) = \sum_{x_{t}}^{} p(x_{t+1}|x_{t}) bel(x_{t})\)

(recall \(P_{ij} = p(x_{t+1}= i| x_t=j)\)).

bel_pre = bel.copy()
################## Fill Your Code! ##################
# Without State Transition Matrix
# State Transition
bel = np.zeros_like(bel_pre)
for i in range(4):
  for j in range(4):
    bel[i] += P[i,j]*bel_pre[j]
#####################################################
print(bel)
[[0.25]
 [0.25]
 [0.25]
 [0.25]]

This computation is of course much simpler as a matrix–vector product.

################## Fill Your Code! ##################
# With State Transition Matrix
# State Transition
bel = np.zeros_like(bel_pre)
bel = P @ bel_pre
#####################################################
print(bel)
[[0.25]
 [0.25]
 [0.25]
 [0.25]]

The reason for studying the measurement model and the state transition model is to understand the hidden Markov model (HMM).

4.1.2 Five observations

If the observations are \(z_{1:5}=\{sensor\_open, sensor\_closed, sensor\_closed, sensor\_open, sensor\_open\}\), how does \(p(open|z_{1:n})\) evolve over time?

We solve this using both the measurement model and the state transition probability (the door does not move, so the transition matrix is the identity).

  • State set \(X = \{open, closed\}=\{O, C\}\)

  • Observation set \(Z = \{sensor\_open, sensor\_closed\}=\{SO, SC\}\)

  • Measurement model \(P_{zx}\)

    • \(p(z_{t}=SO | x_{t}=O) = 0.75\)
    • \(p(z_{t}=SC | x_{t}=O) = 0.25\)
    • \(p(z_{t}=SO | x_{t}=C) = 0.1\)
    • \(p(z_{t}=SC | x_{t}=C) = 0.9\)

  • State transition probability \(P_{x'x}\)

    • \(p(x_{t+1}=O | x_{t}=O) = 1\)
    • \(p(x_{t+1}=C | x_{t}=O) = 0\)
    • \(p(x_{t+1}=O | x_{t}=C) = 0\)
    • \(p(x_{t+1}=C | x_{t}=C) = 1\)
################## Fill Your Code! ##################
# Define Measurement Model Matrix
P_zx = np.array([ [0.75,  0.1],
                  [0.25,  0.9]])

# Define State Transition Matrix
P_xx = np.array([ [1, 0],
                  [0, 1]])

# Initial State Probability(Belief)
bel = np.ones((2,1))
bel = bel/np.sum(bel)

# Observation Sequence
obs = [0, 1, 1, 0, 0]
#obs = [0,0] #0 is open
# State Transition with Observation
for i in range(len(obs)):
  bel = P_xx@bel
  bel = P_zx[obs[i],:].reshape((2,1)) *bel
  bel = bel/np.sum(bel)     # normalization
  print(bel[0])             # P(open | z_1:t): row 1 is p(O|SO), row 2 is p(O|SO,SO), ...

4.2.2 The Decoding Problem

Given \(z_{1:n}, P_{x'x}, P_{zx}\), find the state sequence \(x_{1:n}\) that produced \(z_{1:n}\).

Here we take the greedy approach of choosing the most probable state of \(bel(x)\) at each step of the evaluation problem.

  • Path : sequence of states
  • \(w == x\) : state
  • \(v == z\) : observation
  • \(\alpha_t == bel_t\) : belief
  • \(a_{ij} == P_{x'x}\) : state transition probability (index order reversed)
  • \(b_{jk} == P_{zx}\) : measurement model (index order reversed)

P_xx[0,0] = 0.6; P_xx[1,0] = 0.3; P_xx[2,0] = 0.1
P_xx[0,1] = 0.5; P_xx[1,1] = 0.2; P_xx[2,1] = 0.3
P_xx[0,2] = 0.5; P_xx[1,2] = 0.3; P_xx[2,2] = 0.2

P_zx = np.zeros((2,3))
P_zx[0,0] = 0.9; P_zx[0,1] = 0.6; P_zx[0,2] = 0.2;
P_zx[1,0] = 0.1; P_zx[1,1] = 0.4; P_zx[1,2] = 0.8;

Path = []

  j = np.argmax(bel)
  Path.append(j)

4.3 Limitations of HMMs and the Need for RNNs

For reference, a generic implementation of the HMM forward algorithm (\(\alpha\) recursion) on a small 3-state model:

import numpy as np

def forward_algorithm(pi, A, B, observations):
    T = len(observations)
    N = len(pi)

    # Step 1: Initialization
    alpha = np.zeros((T, N))
    alpha[0, :] = pi * B[:, observations[0]]

    # Step 2: Recursion
    for t in range(1, T):
        for j in range(N):
            alpha[t, j] = np.sum(alpha[t-1, :] * A[:, j]) * B[j, observations[t]]

    # Step 3: Termination
    P_O_given_lambda = np.sum(alpha[-1, :])

    return P_O_given_lambda, alpha

# HMM parameters
pi = np.array([0.4, 0.3, 0.3])  # initial state distribution
A = np.array([[0.5, 0.2, 0.3],   # transition matrix
              [0.3, 0.5, 0.2],
              [0.2, 0.3, 0.5]])
B = np.array([[0.7, 0.1, 0.2],   # emission matrix
              [0.1, 0.6, 0.3],
              [0.3, 0.2, 0.5]])

# Observation sequence
observations = [0, 1, 2, 0, 1]

# Likelihood via the forward algorithm
probability, alpha_matrix = forward_algorithm(pi, A, B, observations)

# Print results
print(f"Probability of the observation sequence: {probability}")
print("Alpha matrix from the forward algorithm:")
print(alpha_matrix)

import numpy as np

# 4x4 random matrix (toy data)
data = np.random.rand(4, 4)

# Standardize
mean = np.mean(data, axis=0)
normalized_data = data - mean

# Covariance matrix
covariance_matrix = np.cov(normalized_data, rowvar=False)

# Eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(covariance_matrix)

# Sort components by decreasing eigenvalue
sorted_indices = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[sorted_indices]
eigenvectors = eigenvectors[:, sorted_indices]

# Keep the first two principal components
num_components = 2
selected_eigenvectors = eigenvectors[:, :num_components]

# Project the data
data_pca = np.dot(normalized_data, selected_eigenvectors)

# Print results
print("Original Data:")
print(data)
print("\nPrincipal Components:")
print(selected_eigenvectors)
print("\nData after PCA:")
print(data_pca)
