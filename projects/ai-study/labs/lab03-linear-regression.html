Lab 3 · Linear & Polynomial Regression

Normal equation vs. gradient descent, with a scikit-learn comparison

Linear and polynomial regression solved analytically and numerically.
NoteAbout this edition

English text and comments were edited for publication. Outputs are archived notebook results, not newly executed results. Lab scaffolds and reference illustrations were supplied by the course. Source and reproducibility notes.

TipSummary

Linear regression is first solved in closed form with the normal equation \(\hat{\theta} = (X^\top X)^{-1} X^\top y\), including polynomial feature expansion for quadratic and cubic data. The same problems are then solved numerically with batch gradient descent on the mean squared error, the effect of the learning rate is visualized, and the result is compared with scikit-learn’s LinearRegression. References point to the lecture slides and Hands-On Machine Learning (Géron).

3.3 Visualizing the Gradient Descent Updates

The green line is the initial model, red lines are intermediate iterates, and the blue line is the model after 15 iterations. Three learning rates are compared: \(\eta = 0.02\) (too small), \(0.10\) (reasonable) and \(0.30\) (too large, the iterates oscillate).

# Ref: Hands-On Machine Learning p.160
eta = 0.02
n_iterations = 15
m = 100

np.random.seed(160)
theta = np.random.randn(2, 1)
for iteration in range(n_iterations):
    gradients = 2/m * X.T.dot(X.dot(theta) - Y)
    new_theta = theta - eta * gradients


    X_new = np.array([[0], [2]])
    X_new_b = np.c_[np.ones((2, 1)), X_new]
    y_predict = X_new_b.dot(theta)
    y_predict

    if iteration == 0:
      plt.plot(X_new, y_predict, 'g-')
    elif iteration == n_iterations-1 :
      plt.plot(X_new, y_predict, 'b-')
    else :
      plt.plot(X_new, y_predict, 'r-')

    theta = new_theta

plt.plot(x, y, 'y.')
plt.axis([0, 2, -1, 12])
plt.grid()
plt.xlabel("X")
plt.ylabel("y")
plt.show()

3.4 Linear Regression with scikit-learn

Hands-On Machine Learning, p. 162

from sklearn.linear_model import LinearRegression
lin_reg = LinearRegression()
np.random.seed(160)
x = 2 * np.random.rand(100, 1)          # random x in [0, 2]
y = 4 + 3 * x + np.random.randn(100, 1) # y = 3x + 4 + noise
lin_reg.fit(x, y)
LinearRegression()
lin_reg.intercept_, lin_reg.coef_  # intercept and slope
(array([4.02548831]), array([[3.062051]]))
x_new = np.array([[0], [2]])
lin_reg.predict(x_new)
array([[ 4.02548831],
       [10.14959031]])
plt.plot(x_new, lin_reg.predict(x_new), 'r-')
plt.plot(x, y, 'y.')
plt.axis([0, 2, 0, 15])
plt.grid()
plt.xlabel("X")
plt.ylabel("y")
