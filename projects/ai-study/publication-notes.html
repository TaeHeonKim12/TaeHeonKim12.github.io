Source & Reproducibility Notes

Authorship, publication edits, archived outputs, and requirements for running the coursework.

Authorship and source material

This collection documents an undergraduate Artificial Intelligence course taken in 2023. Lab notebooks used course-provided scaffolds; marked implementation blocks identify the student’s contributions. Assignments contain substantial student implementation and handwritten derivations. Embedded lecture diagrams, reference tables, and exercise prompts are course-provided material, not original illustrations by the portfolio author. This edition does not establish a license for redistribution of those materials.

The course title, instructor, institution, and original material URLs were not specified in the source site. They are therefore not invented here. No public source repository or notebook download is linked in this edition.

Publication edits and archived results

English prose and comments were edited for presentation. Some redundant/setup cells were omitted. Lab 12 contains post-course completions in dovalueiteration, value2policy, and dopolicyiteration; those functions are labeled on the page and should not be read as unchanged submitted work.

Outputs are snapshots from the original notebooks. Building this site does not execute Python, retrain models, or establish that edited code reproduces the displayed results. Recorded warnings and interrupted runs are retained where relevant. Historical results are demonstrations, not newly verified benchmarks.

Running the examples

This site is a reading archive, not a self-contained executable package. To reproduce a notebook, obtain its original notebook and inputs, inspect its imports, and recreate its environment before running cells in order. Exact package versions and a tested environment lockfile are not available in this edition.

Work Main requirements Additional dependencies
Optimization, neural networks, HMM, value iteration Python, NumPy, Matplotlib; scikit-learn for comparison sections Original notebook inputs; an animation encoder for regenerated videos
TensorFlow and recurrent-network labs TensorFlow/Keras; KoNLPy for Korean text processing Datasets, tokenizer/runtime dependencies, and any cached preprocessing files referenced in the notebook
Object detection Darknet, OpenCV, Google Colab for webcam integration Custom weights, configuration, class definitions, images, and the referenced Drive directory structure

The YOLO assignment includes inference code but not its training notebook or a held-out evaluation. Detection confidence scores do not measure dataset-level accuracy.

Building and hosting this site

With Quarto installed, run quarto render from the project folder. The generated docs/ directory is the complete static site; publish its contents together so relative links, images, scripts, and videos remain available. Rendering does not require the notebook training environments.
